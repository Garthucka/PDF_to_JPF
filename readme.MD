# 📄 PDF to Image Converter (GUI)

Быстрое и удобное десктопное приложение с графическим интерфейсом для пакетной конвертации PDF-файлов в изображения (**JPG, PNG, TIFF, BMP**).

Приложение решает главную проблему библиотеки `pdf2image` — **автоматическую установку и настройку Poppler** (необходимого движка для рендеринга PDF), избавляя пользователя от ручной работы с системными путями.

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Возможности

- 🚀 **Многопоточность** — конвертация до 16 файлов одновременно (настраивается).
- 🖼️ **Многообразие форматов** — поддержка JPEG, PNG, TIFF, BMP.
- ⚙️ **Гибкая настройка качества**:
  - Изменение DPI от 72 (экран) до 600 (печать).
  - Настройка качества сжатия JPEG (1–95%).
- 📂 **Умная организация** — опция сохранения страниц каждого PDF в отдельную подпапку.
- 📊 **Мониторинг в реальном времени** — прогресс-бар, журнал событий (лог) с цветовой подсветкой, расчёт оставшегося времени и скорости.
- 🛑 **Управление** — возможность экстренно остановить конвертацию после текущего файла.
- 🪟 **Скрытый CMD** — на Windows автоматически скрываются чёрные окна консоли при вызове утилит Poppler (патч `subprocess.Popen`).
- 📦 **Автоустановка Poppler** — встроенный загрузчик Poppler для Windows прямо из интерфейса.
- 🧪 **Консольный прототип** — простой скрипт `pdf.py` для быстрого тестирования без GUI.

## 🛠 Требования и зависимости

Для запуска из исходного кода вам потребуется:

1. **Python 3.8+**
2. Библиотеки Python:
   ```bash
   pip install pdf2image Pillow
   ```
3. **Poppler** — движок для чтения PDF:
   - **Windows** — скачивается автоматически по нажатию кнопки в интерфейсе.
   - **Linux**: `sudo apt install poppler-utils`
   - **macOS**: `brew install poppler`

## 🚀 Запуск

### Вариант 1: Запуск из исходного кода (Python)

1. Установите зависимости:
   ```bash
   pip install pdf2image Pillow
   ```
2. Запустите главный скрипт:
   ```bash
   python pdf_to_jpg_gui.py
   ```
3. При первом запуске на Windows нажмите кнопку **«Установить Poppler»** в интерфейсе программы.

### Вариант 2: Консольный прототип (`pdf.py`)

Для быстрого теста без GUI откройте `pdf.py` и укажите свои пути:

```python
pdf_folder   = r"C:\integral\PDF\pdf v"   # ← ваша папка с PDF
jpg_folder   = r"C:\integral\PDF\JPG"     # ← куда сохранять
poppler_path = r"C:\poppler\Library\bin"  # ← путь до папки bin Poppler
```

Запуск:
```bash
python pdf.py
```

### Вариант 3: Запуск из EXE (Windows)

Если вы собрали приложение в `.exe` файл (см. раздел ниже), Poppler уже встроен внутрь. Никаких дополнительных установок не требуется — просто запустите `.exe`.

## 🏗 Сборка в EXE (PyInstaller)

Чтобы создать автономный `.exe` файл со встроенным Poppler:

1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```
2. Скачайте Poppler в папку для бандла с помощью вспомогательного скрипта:
   ```bash
   python download_poppler.py poppler_bundle
   ```
3. Запустите сборку, добавив папку с Poppler в ресурсы:

   **Windows** (разделитель `;`):
   ```bash
   pyinstaller --noconfirm --onefile --windowed ^
       --add-data "poppler_bundle;poppler_bin" ^
       --name "PDF_Converter" ^
       pdf_to_jpg_gui.py
   ```

   **Linux / macOS** (разделитель `:`):
   ```bash
   pyinstaller --noconfirm --onefile --windowed \
       --add-data "poppler_bundle:poppler_bin" \
       --name "PDF_Converter" \
       pdf_to_jpg_gui.py
   ```

Готовый `.exe` файл появится в папке `dist/`.

> 💡 **Совет:** при сборке на Windows можно добавить иконку через параметр `--icon=icon.ico`.

## 💡 Советы по использованию (DPI)

| DPI  | Назначение                              | Скорость / Размер       |
|------|-----------------------------------------|-------------------------|
| 72   | Черновик / просмотр на экране           | ⚡ Очень быстро / малый |
| 150  | Стандартное качество для чтения         | 🟢 Быстро / средний     |
| 200  | **Рекомендуемый баланс** качества       | 🟡 Оптимально           |
| 300  | Высокое качество (текст, графики)       | 🟠 Медленнее / большой  |
| 600  | Подготовка к печати                     | 🔴 Очень медленно / огромный |

## 🎨 Интерфейс

Приложение разделено на две вкладки:

- **Основное** — выбор папок, настройка DPI, запуск конвертации, прогресс-бар.
- **Настройки** — формат вывода, качество JPEG, количество потоков, опция подпапок, информация о Poppler.

В нижней части окна расположен **цветной журнал событий** с тегами:
- 🟢 `ok` — успешные операции
- 🔴 `err` — ошибки
- 🔵 `info` — информационные сообщения
- 🟡 `warn` — предупреждения
- 🟦 `done` — завершение задач

## 🐛 Известные особенности

- На Windows при использовании многопоточности (`ThreadPoolExecutor`) и большого количества файлов может возникать высокая нагрузка на диск. Рекомендуется:
  - **SSD** — 4–8 потоков
  - **HDD** — 2–4 потока
- Если автоматическая загрузка Poppler блокируется антивирусом/брандмауэром, скачайте архив [Poppler for Windows](https://github.com/oschwartz10612/poppler-windows/releases) вручную, распакуйте его и поместите папку `bin` в директорию `poppler/` рядом со скриптом.
- При работе с очень большими PDF (сотни страниц) рекомендуется снижать DPI до 150–200 и использовать формат JPEG с качеством 75–85.
